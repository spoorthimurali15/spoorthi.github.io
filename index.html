Medical Imaging & Deep Learning
Sparse-View Lung Nodule Volumetry via AReT: Anatomy-Regularized TensoRF Under Review
M Spoorthi, P Suja
Manuscript under review · 2026
Developed an advanced deep learning framework for 3D lung nodule reconstruction and volumetric analysis from only three orthogonal X-ray projections, leveraging NeRF and TensoRF architectures to eliminate the need for CT-level radiation exposure.
  • Identified and resolved an unreported TensoRF failure mode - default density shift ∆ = −10 suppresses all density gradients via dead ReLU throughout training - by setting ∆ = 0, restoring gradient flow with zero architectural changes; enables sparse-view X-ray attenuation reconstruction in TensoRF for the first time.
  • Implemented thorax-specific ℓ₁ + TV regularization exploiting air-dominant thoracic anatomy as a physics-informed inductive bias, enabling stable 3D reconstruction from 49,152 training rays with only 869,555 parameters across 3,000 iterations.
  • Integrated Beer–Lambert DRR simulation and HU-calibrated DICOM preprocessing pipeline end-to-end in PyTorch on NVIDIA T4 (~8 min/patient) on LIDC-IDRI (n = 19). Achieved Pearson r = 0.983, Spearman ρ = 0.943 (p < 0.0001), median APE 11.4% - an 8.4× improvement over spherical approximation.
  • Conducted systematic 11-strategy progressive ablation across MedNeRF variants, CheXNet, MONAI UNet, and TensoRF configurations; anatomy-regularized prior-free TensoRF outperforms all generative-prior-guided approaches (Wilcoxon W = 0, p < 0.0001).

AMN: An Adaptive Multi-Scale Fusion Network with Boundary and Uncertainty Modeling for Nuclei Segmentation Accepted · ICETCI 2026
M Spoorthi, P Suja
ICETCI 2026 · 2026 · 🏆 Best Presenter Award
Developed a hybrid deep learning framework for multi-class nuclei segmentation in histopathology images using a dual-encoder architecture combining Swin Transformer and ResNet-50.
  • Implemented adaptive multi-scale fusion mechanism with channel-wise gating (learned sigmoid gate α ∈ [0,1]²⁵⁶) to dynamically blend global context and local texture for seven-class nuclei segmentation in H&E histopathology images.
  • Multi-task prediction head producing simultaneous binary segmentation, boundary detection, seven-class classification, and heteroscedastic uncertainty outputs; trained with composite loss of class-weighted focal (γ=2.0), boundary-aware BCE (positive weight 10×), and uncertainty-modulated cross-entropy.
  • Achieved mean F1 of 0.6869 and F1Ly of 0.8187 on CoNIC (+12.6 points over ResU-Net); highest binary F1 on MoNuSeg in zero-shot cross-dataset evaluation without retraining.
  • Addressed severe class imbalance (background 83.87%, rare classes <1%) via per-class focal weights, weighted random sampling, and boundary-aware supervision; trained with AdamW, cosine annealing, 5-epoch linear warmup.
